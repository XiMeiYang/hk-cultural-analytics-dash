# 课堂汇报稿（约1—2分钟）

我们的主题是“香港公共文化消费的多维可视分析”。我负责空间维度的问题4、5，以及类别维度的问题5，用Python、Plotly和Dash做成交互页面。

第一步，我看文化活动在哪里。我把当前事件与场地坐标连接，将同一设施的不同厅室合并，再和历史场地统计对照。用事件密度图展示聚集位置，用双变量地图同时表现历史份额与当前事件份额。这里两个数据源的活动范围不同，所以我把“验证”理解为探索性空间对照，不直接声称证明了恢复趋势。

第二步，我看场地和活动类别如何组合。我建立场地—类别二部图，连线权重是事件数，用二部模块度寻找社区，再以力导向图、社区热力图和社区地图展示。默认有8个社区，但改变分辨率后会得到5到9组，所以也展示参数敏感性。

第三步，我看不同艺术类别的参与方式。我用HKADC调查，把实体和非实体的重叠拆成“仅实体、仅非实体、两者都有”，再做对应分析双标图。旁边的条形图展示非实体参与占比。报告把电视、广播也算非实体，因此我不会把它直接叫作纯线上参与率。

这三个问题连成的故事是：活动在哪里、场地与类别怎样连接，以及观众通过什么方式参与。页面可以筛选、查看节点信息并下载分析表。

## 老师可能追问

**为什么不直接做18区填色地图？** 原始包没有区界文件，且我的空间比较可以在有坐标的共同设施层面完成。若小组另行补齐并核对区界，可接入点落区流程，不能用大致坐标猜区。

**为什么问卷不能跟地图直接合并？** 公开问卷表没有地区键，也没有个人记录；场地位置不是受访者住址。

**社区是不是场地真的在合作？** 不是，它表示活动类别分布形成的统计组合。

**CA两维加起来100%，是不是效果特别好？** 不是，只有3个互斥模式，本来最多只有2个有效维度。

**数据清洗做了什么？** 查主键、统一代码大小写、去历史场地代码空格、合并厅室、保留缺失、排除汇总行和区域集合场地、核对问卷百分比的包含排除关系。
